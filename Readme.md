# instructions to run the project 

## 1. to run the project in dev environment  
### ```cd part5``` (if you are not already in part5 directory)
### ```npm run dev``` 


# Instructions to run end-to-end tests using paywright (run the below commands in another terminal)
### ```cd e2e``` (if you are not already in e2e directory)
### To run playwright tests: ```npm test``` 
### To run playwright test and see reports: ```npm test:report``` 
### To run playwright tests with UI: ```npm run test -- --ui```
